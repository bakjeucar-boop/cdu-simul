# cdu-simul

AI/GPU 서버 D2C(Direct-to-Chip) 액체냉각 CDU를 파이썬 물리모델로 시뮬레이션해,
정상/이상/누출 시나리오 데이터를 생성하기 위한 저장소.

**현재 파일럿(feasibility study) 단계다.** 실제 설계사양이 없어 모든 수치가
가정값이며, 목표는 정확도가 아니라 모델 구조가 물리적으로 무너지지 않는지 확인하는
것이다. 산출물은 전부 "가정값 기반 — 실측 아님"으로 다룬다.
