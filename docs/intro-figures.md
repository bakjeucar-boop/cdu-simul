**이 문서가 하는 일**: `docs/intro-outline.md` §4·§5 에 적힌 수치를 **지금 코드로
다시 확인해** 한 자리에 모은다. 소개자료 HTML 을 만들 때 이 표의 값을 쓴다.
outline 을 고치지 않았다 — 다른 값은 **둘 다** 적었다.

**이 문서가 하지 않는 일**: 게이트 재판정 · 모델 수정 · 값이 다른 이유의 설명.
관측만 적었고 짐작을 섞지 않았다.

## 2. 값이 갈린 셋 — 펼쳐 적는다

### ① cp 평가 = 환수온도의 balance 잔차 (표 #11) — **멈춤 조건에 걸린다**

| 기준 | 값 [%] |
|---|---|
| PROCEED 세션 1-B 기록 (「다음 세션이 알아야 할 결정」 3) | 0.31524 |
| 지금 코드 재산출 (2026-09-03) | 0.3152212 |

차이 = 0.0000188 %p. 같은 표의 다른 두 값(`bulk_mean` 0.00506 · `supply` 0.30891)은
기록과 **같다**. `return` 하나만 다르다.

- **이 판은 아무것도 고치지 않았다.** 게이트 재판정은 이 판의 일이 아니다
  (`CLAUDE.md` 「멈추는 조건」).
- 판정 방향은 바뀌지 않는다 — 세 값 모두 6장 기준 0.1% 대비 같은 쪽에 있다
  (`bulk_mean` 통과 · `supply`·`return` 실패).
- outline §4 가 적은 표기(0.315%)는 두 값 모두에서 같다.
- **차이의 원인은 적지 않는다.** 이 판은 관측 판이다.

### ② 저항 +50% 총유량 변화 (표 #14)

| 기준 | 값 [%] |
|---|---|
| PROCEED 세션 4 신호표 | −0.3704 ~ −0.1638 |
| 지금 코드 재산출 (2026-09-03) | −0.3710 ~ −0.1642 |

같은 32조합·같은 진입점(`leak.all_steady_signals()`)이다. outline §5 의 표기
(−0.16~0.37%)는 두 값 모두에서 같다. **원인은 적지 않는다.**

### ③ 데모 케이스 집합의 총유량 변화 (표 #15)

−0.2590 ~ −0.2586% 는 **표 #14 와 다른 것을 잰 값이다.** 나란히 놓지 않는다.

| | 표 #14 (세션 4 경로) | 표 #15 (데모 경로) |
|---|---|---|
| 케이스 집합 | 수력 32조합 · 부하 100% 고정 | 구성 2 × 부하 17단계 = 34 · 고정축 1조합 |
| 랙별 등가길이 배분 | **끔**(균등) | **켬** |
| 비교 대상 | 같은 조합의 정상 해 | 같은 구성·부하의 R0 해 |

소개자료에 「저항 +50% 에서도 총유량은 거의 안 움직인다」를 쓸 때 **어느 쪽 수치를
쓰는지 밝혀야 한다.** 두 값의 폭이 다르다(−0.16~0.37% 대 −0.259%).

## 3. 나란히 읽으면 안 되는 것 (5-1 「2차측 유체」 규정)

`hydraulics` 산출물 말미가 그대로 적고 있다:
**「Cr 은 5-1 이 선언한 1 이 아니라 물성에서 유도된 값이다(세션 5-B). 세션 5-B
이전 로그의 수치는 이후 것과 나란히 읽을 수 없다.」**

이 표의 값은 **전부 2026-09-03 시점 코드에서 다시 낸 것**이거나(재산출 표시),
세션 5-B **이후**에 생성된 `demo/demo_steady.json`(`demo-7.2-B`)에서 읽은 것이다.
표 #11 · #14 의 「기록값」 열만 세션 5-B 이전 로그이며, 그 자리에서만 비교 목적으로
적었다 — **소개자료 본문에 옮기지 않는다.**

## 4. outline 에서 눈에 띈 것 — 목록만 (이 판에서 고치지 않았다)

1. §4 3-1 「열교환기 640 kW · 공급 32.169 ℃」와 §4 3-2 ③ 「32.17 / 42.47 ℃」가
   같은 케이스(`single/L100/R0`)의 값인데 자릿수가 다르게 적혀 있다.
2. §5 ⑵ 「양정 변화가 양정 대비 상대 5e-5 수준」에 **어느 저항 수준인지**가 없다.
   재산출값은 +5% 수준이 4.3e-5~9.8e-5, +50% 수준이 3.9e-4~8.8e-4 로 한 자릿수
   차이가 난다 (표 #12 · #13).
3. §5 ⑵ 「저항 +50 % 에서도 총유량 변화는 −0.16~0.37 %」에 케이스 집합 표시가 없다.
   데모 화면의 같은 축(저항 50%)에서는 −0.259% 다 (§2 ③).
4. §4 3-1 의 네 수치(총유량·랙별 유량·공급온도·출구온도)에 케이스 조건
   (단일 CDU · 부하 100% · 저항 0% · 고정축)이 붙어 있지 않다.
