**계산보다 먼저 적고 먼저 커밋한다.** 결과를 보고 이 문서를 고치지 않는다.
기준이 결과와 안 맞으면 기준을 고치지 않고 그 사실을 보고에 적는다

## 0. 이 판정이 무엇이고 무엇이 아닌가

세션 4 게이트는 「막힘」(K값 증가)만 판정했다. 「샘」(질량손실)에는 게이트가 없었고
관측만 있었다(세션 5.6 · 5.6-B · 5.7-D). 이 판은 **세션 4 가 쓴 판정 기준 셋을
「샘」 행에 그대로 적용해** 전수 판정한다.

**「통과」의 뜻은 「모델 안에서 신호가 잡음 위에 있다」까지다.** 「실측으로 감지
가능하다」는 뜻이 아니다 — 계측기 사양이 없고 실측이 없다(세션 4 판정에 붙은
단서와 같다).

**이 판이 판정하지 않는 것**

- **energy balance (6장 ①).** 「샘」 행은 누출 엔탈피 항 없이는 닫히지 않고
  (세션 5.7-D: 빼면 최대 1.2129 % · 넣으면 0.000062 %), 그 항을 넣는 것은 물리
  모델 변경이라 이 판의 범위 밖이다. CSV 의 `energy_balance_residual_percent` 는
  「샘」 행에서 빈 값이다(`dataset.py:789`). **미판정으로 남긴다.**
- **전이(시간축).** 「샘」 전이 행은 데이터셋에 없다(미해결 #40 · #38).
- **신호 크기가 실제 누출 감지에 충분한가.** 실측이 없어 판정 불가.

## 2. 「샘」에 적용할 때의 정의

### 2-1. 판정 대상

`results/cdu_dataset.csv` 의 `leak_model == "massloss"` 행 **13,824행 전수**.
재계산하지 않는다 — 이미 만들어진 CSV 를 읽어 판정만 한다.

### 2-2. 비교 대상 (무엇 대비 무엇인가)

같은 운전조건의 **정상 행**(`scenario_kind == "정상"` · `leak_model == "K_approx"` ·
`blockage_level_percent == 0`) 하나. 짝짓는 열 여덟:

```
pump_head_rated_mAq · branch_dp_rated_mAq · valve_dp_rated_mAq · ntu ·
T_secondary_supply_C · cdu_config · cdu_index · load_percent
```

정상 행은 320개이고 이 여덟 열로 **유일하게 갈린다**(32조합 × 부하 2 ×
구성별 행 5 = 320). 「샘」 행의 구조 자유도 셋(`residual_return_share` ·
`pump_sees_supply_flow` · `share_uses_return_flow`)에는 대응하는 정상 행이 없다 —
누출이 0 이면 `Q_ret = Q_sup` 이라 셋이 해에 영향하지 않기 때문이며, 그래서
정상 행 하나가 여러 「샘」 행의 기준선이 된다(1:다).

**한계 — 기준선이 다른 solver 경로를 탄다.** 「샘」 행은
`massloss.solve_massloss` · `massloss_thermal.solve_massloss_steady` 로 풀리고
(`dataset.py:730-745`), 정상 행은 `model.solve_cdu_steady_state` 로 풀린다
(`dataset.py:529`). 세션 4 는 정상과 누출이 **같은 경로**를 타게 해서 차이가
기구 때문임을 보장했다(`dataset.py:451-452` · 세션 4 C2). 「샘」에는 같은 배치의
`Q_massloss = 0` 해가 CSV 에 없으므로 그 보장이 없다. 두 경로가 `Q_massloss → 0`
에서 같은 식으로 수렴하는 것은 `massloss_thermal.py:19-30` 의 구성에서 읽히지만
**이 판은 그것을 재지 않는다.** 따라서 Δ 에는 경로 차가 섞여 있을 수 있다.
아래 2-5 의 「해당 없음」 건수가 그 경로 차의 **수력 쪽 상한**을 같이 준다 —
세션 5.6 관측 ④ 가 다섯 양이 정확히 0 이라고 한 배치에서 Δ 가 0 이 아니면
그 크기가 곧 경로 차다.

### 2-3. 어느 열을 보는가 — 신호 다섯

| 신호 | 열 | 단위 |
|---|---|---|
| ⑴ 총유량(=랙이 받는 헤더 공급유량) | `total_flow_Lps` | 상대 % |
| ⑵ 펌프 양정 | `pump_head_mAq` | mAq |
| ⑶ 주입랙 통과유량 | `rack0_flow_Lps` | 상대 % |
| ⑷ 타 랙 유량 | `rack1_flow_Lps` | 상대 % |
| ⑸ 주입랙 출구온도 | `rack0_outlet_C` | K |

- 상대 % 는 세션 4 와 같은 정의다: `(after − before) / before × 100`
  (`src/cdu_simul/leak.py:111`).
- **랙0 을 「주입랙」으로 읽는다.** 「샘」 행의 `anomaly_rack_index` 는 빈 값이지만
  (오독 방지 · `dataset.py:494-501`), 주입 지점 자체는 5-1 「「샘」 주입 지점」이
  정한 `LEAK.injection_rack_index = 0`(`assumptions.py:494`)이고 코드도 그
  지점에 건다. 「샘」은 랙에 국소화되지 않으므로(랙 간 비대칭 2.220e-16 L/s ·
  세션 5.6) ⑶ 과 ⑷ 는 같이 움직인다 — 세션 4 처럼 갈라지지 않는 것이 정상이다.
- **타 랙은 랙1 하나로 본다** — 세션 4 가 쓴 `_other_rack_index`
  (`src/cdu_simul/massloss.py:273-275`)와 같다.

### 2-4. 기대 부호 (기준 A) — 「샘」을 진 CDU 기준

「샘」의 기대 부호는 「막힘」과 **정반대이거나 배치에 따라 갈린다.** 아래는 전부
이미 관측된 것을 옮긴 것이고 이 판이 새로 고른 것이 아니다.

| 신호 | 기대 부호 | 출처 |
|---|---|---|
| ⑴ 총유량 | **+ (증가)** | 미해결 #36 관측(`PROCEED.md:9223`): 질량손실 +3.0e-03 ~ +1.5e-01 L/s · K 근사와 정반대 |
| ⑵ 펌프 양정 | `pump_sees_supply_flow`=True → **−** / False → **+** | 같은 곳: 「펌프가 공급유량을 보면 하강, 환수유량을 보면 상승」 |
| ⑶ 주입랙 통과유량 | **+ (증가)** | 같은 곳: 「주입랙 통과유량도 K 근사 감소·질량손실 증가로 정반대」 |
| ⑷ 타 랙 유량 | **+ (증가)** | 같은 곳: 「랙에 국소화되지 않아 ⑶ 과 ⑷ 가 같이 움직인다」 |
| ⑸ 주입랙 출구온도 | **− (하강)** | 세션 5.7-D(같은 곳): 「주입랙 출구온도와 CDU 환수온도가 K 근사(+)와 질량손실(−)에서 정반대이고 1,536건 전 조합에서 뒤집히지 않는다」 |

**이웃 CDU 행(`cdu_index != anomaly_cdu_index`)에도 같은 기대를 적용한다** —
다만 위 기대는 전부 **「샘」을 진 CDU** 에서 나온 것이므로, 이웃 CDU 에서
실패하면 그것은 **「기대가 이웃까지 미치지 않는다」**는 뜻이고 모델 결함이
아니다. **실패 건수는 `cdu_index` 로 반드시 갈라 적는다.** 이웃 CDU 의 기대
부호를 이 판이 새로 유도하지 않는다(짐작하지 않는다).

### 2-5. 「해당 없음」의 정의 (세션 7.45 원문 · **개정됨**)

> **[개정 · 세션 7.47]** 이 절의 **수치 경계**와 2-6 의 「해당 없음」 줄 셋은
> 아래 **2-5-B** 가 대신한다. 아래 원문은 **세션 7.45 판정이 실제로 쓴 규정**이라
> 지우지 않고 남긴다 — 두 판정의 건수가 왜 다른지는 여기서만 읽힌다.

사람이 정한 것: **「수력 흔적이 없는 배치는 실패가 아니라 해당 없음으로 따로
센다.」**

수치 경계: **어떤 신호의 Δ 가 그 신호 단위로 |Δ| ≤ 1.0e-12 이면 「흔적 없음」**
으로 읽고, 그 (행 · 신호) 짝을 **해당 없음**으로 센다. 유량은 L/s, 양정은 mAq,
온도는 K 의 **절대 Δ** 로 잰다(상대 % 로 재지 않는다 — 아래 출처가 절대값으로
잰 것이라서다).

**경계의 출처.** 1.0e-12 는 새 임계값이 아니라 `src/cdu_simul/massloss.py:102`
의 `_SIGN_ZERO_TOL` 이다. 세션 5.6 이 「부호를 0 으로 읽는 절대 임계」로 정해
`sign_summary`(`:360-366`)가 그대로 쓴 값이고, 관측 ④ 의 **「다섯 양이 전부
정확히 0」** 이라는 판정이 이 임계로 내려졌다(`PROCEED.md:1520` · `:1676` ·
`:2285`). 그 주석이 근거를 함께 적는다 — 세션 3-A/3-B 가 관측한 압력평형
잔차(~1e-15 mAq)·유량 균등성 잔차(상대 1e-9)보다 크고, 「샘」이 내는 신호
(1e-5 이상)보다 네 자리 이상 작다.

**해당 없음이 몰릴 것으로 예상되는 배치**(맞는지 C3-라 에서 확인한다):
`residual_return_share == 0.0` 이고 `pump_sees_supply_flow == True` 인 배치 —
세션 5.6 관측 ④ 가 수력 다섯 양이 전부 정확히 0 이라고 한 그 배치다. 온도
신호 ⑸ 는 그 배치에서도 살아 있다(세션 5.7-D: −7.368e-02 ~ −1.886e-03 K)
— 그래서 「해당 없음」을 **행 단위가 아니라 (행 · 신호) 짝 단위로 센다.**

### 2-5-B. 「해당 없음」 규정 — 물리로 다시 세운 것 (세션 7.47)

**계산보다 먼저 적고 먼저 커밋한다.** 재집계 결과를 보고 이 절을 고치지 않는다.

**(가) 옛 규정이 무엇을 물었는가 · 무엇을 물어야 했는가**

- 옛 규정이 물은 것: **「이 (행 · 신호) 짝의 Δ 가 1.0e-12 보다 작은가.」**
  ─ 신호의 **크기**를 묻는 물음이다.
- 물어야 할 것: **「이 행의 배치에서 「샘」이 그 신호를 움직일 수 있는가.」**
  ─ 신호의 **성립 여부**를 묻는 물음이다. 사람이 정한 문언(「수력 흔적이 없는
  배치」)도 크기가 아니라 **배치**를 가리킨다.

**(나) 새 규정.** (행 · 신호) 짝은 아래 둘을 **동시에** 만족할 때, 그리고 그때만
「해당 없음」이다.

1. 그 행이 **「샘」의 수력 응답이 항등적으로 0 인 배치**에 속한다 —
   데이터셋 열로 `residual_return_share == 0.0` **이고**
   `pump_sees_supply_flow == True` (이하 **퇴화 배치**).
2. 그 신호가 **수력 넷** 중 하나다 — ⑴ 총유량 · ⑵ 펌프 양정 ·
   ⑶ 주입랙 통과유량 · ⑷ 타 랙 유량.

**그 배치가 왜 그런가 — 식으로.** `solve_massloss` 의 수력식
(`src/cdu_simul/massloss.py:175-193`)에서 `massloss_flow_Lps`(=Q)가 들어가는
자리는 둘뿐이다.

    available = pump_head(Q_pump)
              − residual_dp(Q_sup, (1−g)·C)
              − residual_dp(Q_ret, g·C)          여기서 Q_ret = Q_sup − Q

- `g = 0` 이면 셋째 항이 `residual_dp(Q_ret, 0·C) = 0` 이라 **Q 가 사라진다.**
- `pump_sees_supply_flow = True` 이면 `Q_pump = Q_sup` 이라 **첫 항에서도 사라진다.**

남는 식은 Q 를 포함하지 않는다 — 물성 온도 `T_prop` 를 고정하면 **Q 가 얼마든
같은 해**이고, 그 해는 `Q = 0` 일 때의 식
(`g·C·Q_sup² + (1−g)·C·Q_sup² = C·Q_sup²` · `massloss.py:158-165`)과 항등이라
K 근사 정상식과도 같다. 세션 7.46 이 이것을 재서 확인했다: 퇴화 배치 256건에서
5.6 경로(물성 37 ℃ 고정) Δ 가 **전부 정확히 0** 이고, 기준선 경로 몫도 배치 6
전수에서 **0**(g=0.5 의 1.147813e-14 % 는 부동소수 잡음)이다(7.46 D2-가 · D3-가).

따라서 데이터셋의 퇴화 배치 Δ 가 0 이 아닌 것은 **수력 응답이 아니다** — 남은
채널은 **물성 평가 온도 하나**이고(7.46 D6: 온도만 옮긴 예측이 실제를 차
0.000e+00 로 덮는다), 그것은 열이 수력에 남기는 몫이지 「샘」의 수력 흔적이 아니다.

**(다) 수치 임계를 쓰지 않는다.** 이 규정에 임계값·허용오차가 **하나도 없다** —
두 열의 값 조합과 신호 목록만으로 갈린다. `_SIGN_ZERO_TOL`(1.0e-12)은 이 규정에
쓰이지 않는다. **규정을 쓰다가 새 수치가 필요해지면 쓰지 않고 사람에게 올린다.**

**(라) 「막힘」에는 성립하지 않는다.** 「막힘」에는 이 구조 자유도가 없다(5-1 —
`residual_return_share`·`pump_sees_supply_flow` 는 「샘」 행에만 있는 열이고
「막힘」 행에서는 빈 값이다). 그래서 「막힘」의 「해당 없음」은 **규정상 0건**이다.

**(마) 무엇에서 무엇으로 바뀌었는가**

| | 옛 규정 (세션 7.45) | 새 규정 (세션 7.47) |
|---|---|---|
| 무엇을 묻는가 | Δ 의 크기 | 행의 배치 |
| 판별식 | `|Δ| ≤ 1.0e-12` (신호 단위) | `residual_return_share == 0.0` 이고 `pump_sees_supply_flow == True` 이고 신호가 수력 넷 |
| 수치 임계 | 쓴다(`massloss.py:102` `_SIGN_ZERO_TOL`) | **쓰지 않는다** |
| 온도 ⑸ | 같은 임계로 함께 갈렸다 | **덮지 않는다** — 퇴화 배치에서도 응답한다(7.45: 온도 7,680건 전부 통과) |
| 퇴화 배치의 수력 넷 | 「실패」 (7.45 D2-다: 5,120짝) | 「해당 없음」 |

**세션 7.45 의 판정은 옛 규정으로 내려진 것이고 그대로 둔다.** 세션 7.47 의

### 2-6. 통과 / 실패 / 해당 없음의 경계

각 기준은 **(행 · 신호) 짝** 마다 셋 중 하나로 갈린다. 셋의 합 = 판정 대상 짝 수.

> **[개정 · 세션 7.47]** 아래 세 기준의 「해당 없음」 줄(`|Δ| ≤ 1.0e-12`)은
> **2-5-B 의 배치 규정**으로 바뀌었다. 통과·실패의 정의는 그대로다.
> 기준 B 의 「해당 없음」은 무리 전체가 퇴화 배치일 때다 — 배치는 무리 안에서
> 상수이므로(무리 키에 구조 자유도 셋이 들어간다) 갈리지 않는다.

**기준 A — 부호 일관성**

- 해당 없음: |Δ| ≤ 1.0e-12 (그 신호 단위)
- 통과: Δ 의 부호가 2-4 의 기대와 같다
- 실패: 그 밖

**기준 B — 수준 간 단조**

같은 (짝짓는 여덟 열 + `residual_return_share` + `pump_sees_supply_flow` +
`share_uses_return_flow`) 안에서 `massloss_size_fraction` 을 0.25 → 0.50 →
0.75 → 1.00 으로 놓고 |Δ| 가 **엄격히 커져야** 한다(세션 4 와 같은 엄격 단조).
「막힘」의 3수준이 「샘」에서 크기 4수준이 되는 것 말고는 같다.

- 판정 단위는 **(무리 · 신호)** 짝이다(무리 하나 = 행 4개).
- 해당 없음: 네 수준의 |Δ| 가 **전부** ≤ 1.0e-12
- 통과: |Δ| 가 네 수준에 걸쳐 엄격 증가
- 실패: 그 밖(부분적으로만 0 인 경우 포함 — 그 경우는 실패로 센다)

**기준 C — 잡음 대비**

가장 작은 크기 `massloss_size_fraction == 0.25` 행만 본다.

- 해당 없음: |Δ| ≤ 1.0e-12 (그 신호 단위)
- 통과: 유량 셋은 |Δ%| > 1.0e-3 % · 양정은 |Δ| > 1.0e-4 mAq ·
  온도는 |Δ| > 1.0e-3 K
- 실패: 그 밖 (0 은 아니지만 잡음 임계를 못 넘는 자리)
