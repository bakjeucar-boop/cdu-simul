### 3-3. 공정 엔지니어가 보기에 빠져 있거나 어색한 자리 (다)

#### ㄱ. 열교환기 ε-NTU 와 대향류 가정

- **봤다**: `model.py:165-183` `hx_effectiveness_counterflow` —
  `ε = (1−e^{−NTU(1−Cr)}) / (1−Cr·e^{−NTU(1−Cr)})`, `Cr=1` 이면 `NTU/(1+NTU)`.
  대향류 식으로 **맞다**. `hx_capacity_terms` (:199-245) 가 `C_min` 을 매번 판정하고
  Cr 을 유도한다(5-B 이후) — 맞다. 2차측 물성을 **공급온도**에서 평가하는 것(:230-232)은
  1차측 벌크평균 규약과 비대칭이지만 2차측 출구온도가 모델에 없어 강제된 것이고
  docstring 이 그것을 적었다.
- **어색한 자리 1 — NTU 가 상수다.** `model.py:243` 이 5장 NTU(2~3)를 유량과 무관하게
  넣는다. 물리적으로 고정인 것은 **UA** 이고 `NTU = UA/C_min` 이다. 「막힘」으로 1차측
  유량이 −9.7 % 까지 움직이고(`dataset_report.py:352` 문언), 「샘」에서 HX 를 지나는
  것이 `ṁ_ret` 로 줄어드는데(`massloss_thermal.py:226-228`) NTU 는 그대로다. 게다가
  `C_min` 이 2차측이면 1차측 유량 변화가 NTU 에 안 걸리고, 1차측으로 뒤집히면 걸린다 —
  **어느 쪽이 `C_min` 인지에 따라 NTU 고정의 뜻이 달라진다.**
  `dataset_report.py:355-358` 이 이것을 「열린 한계」로 이미 적었다.
  **어떻게**: 정격점에서 `UA = NTU × C_min,정격` 을 한 번 역산해 고정하고

#### ㄴ. 펌프곡선·시스템곡선의 교점

- **봤다**: `hydraulics.py:302-352` `residual_resistance_coeff_mAq_per_Lps2` —

  기록이 이미 정직하게 적었다. 문제로 새로 올릴 것은 없다.
- **어색한 자리 3 — 펌프 양정은 ρ 보정이 없고 시스템 저항은 ρ 에 비례한다.**

  읽은 규약과 물리가 여기서 갈린다 — 규약이 정한 대로 돌고 있고 크기가 0.18 % 라
  지금 신호를 가리지는 않는다. **심각도 ㄹ** — 규약이 문서에 있다. 설계데이터가
  펌프곡선을 **압력**으로 주면 그때 규약을 다시 본다.

### 5-4. #40 전이 시간축 — 무엇을 어떻게 다시 세우면 되는가 (마)

**무엇이 문제였나** (세션 5.8 · `PROCEED.md:2509-2560` · #40 행): 2노드 모델을
N-CSTR 로 세분해도 N=64 까지 파형이 수렴하지 않았다 — 직전 N 대비 편차가 16배
세분에 1.25배밖에 안 줄고, t63 이동 방향이 조합마다 갈린다.

**까닭 — 이 리뷰의 읽기**: CSTR 직렬은 **혼합 지연**이고 배관 이동은 **순수 지연**
(플러그 흐름)이다. CSTR N개의 체류시간분포 표준편차는 `τ/√N` 로 줄어 N→∞ 에서
순수 지연으로 가지만, 수렴이 `1/√N` 라 N=64 에서 12 % 폭이 남는다 — 5.8 이 본
「거의 안 준다」가 이것이다. 더구나 현재 구조(`transport_lag.py:18-23`)는 랙과 HX 를
**보유량 0 의 경계 열원**으로 두고 배관만 CSTR 로 나누는데, 실제 계통에서 시간상수를
지배하는 것은 HX·CDU 내부·콜드플레이트 보유량(#21)이지 배관이 아니다. **즉 지금
N-CSTR 은 「작은 M(배관)의 혼합」을 세분하고 있고, 「큰 M(HX·CDU)의 혼합」과
「배관의 순수 지연」은 둘 다 모델에 없다.** N 을 늘려도 후자 둘은 안 생긴다 —
수렴하지 않은 것이 당연하다.

**어떻게 다시 세우는가** — 세 층으로 가르고 각각 5장에서 유도 가능한지 적는다:

1. **순수 지연(배관)** — 각 다리를 `T_out(t) = T_in(t − L/v)` 로 둔다. `L` 은 5장
   등가길이 20~30 m(방침 B 양 끝), `v` 는 그 시점 유량과 5-1 내경에서 나온다
   (정격에서 5.7~8.6 s · 이 리뷰 어림). **새 숫자 0개.** 구현: `solve_ivp` 는 DDE 를
   직접 못 푸므로 (a) 고정 스텝 RK 로 직접 적분하며 지연 버퍼를 든다, 또는
   (b) `dense_output` 을 켠 `solve_ivp` 를 짧은 구간으로 이어 붙이며 이전 구간의
   dense output 에서 `t−L/v` 를 읽는다(방법 of steps). (b) 가 지금 코드(`dynamics.py`)
   에 가깝다 — 적분 구간을 `L/v` 단위로 쪼개는 루프 하나가 는다.
   **등가길이는 압력강하용 개념이라 실제 길이보다 길다(#25)** — 지연도 과대 방향이다.
   5장 「등가길이」를 「배관 길이」로 읽는 것은 5-1 결정이 필요하다.
2. **혼합(HX·CDU 내부·콜드플레이트 보유량)** — 지금 2노드 CSTR 이 이 자리다. M 이
   빠져 있다(#21). 5장에 없어 **설계데이터 없이는 못 채운다.** 다만 「M 을 몇 배로
   두면 t63 이 어떻게 움직이는가」 감도는 지금 코드로 낼 수 있다 — 세션 5.7 이 8배
   보정에서 「τ·t63·t95 가 정확히 8배 이동」을 이미 봤다.
3. **혼합(배관)** — 순수 지연을 넣으면 배관의 CSTR 분할은 필요 없어진다. 배관
   보유량은 1 의 지연 버퍼에 담긴다(플러그 흐름 자체가 보유량이다).

**비용**: `dynamics.py` `_derivative`·`integrate_*` 세 함수 · `plant.py`
`integrate_plant_load_step` · `massloss_thermal.integrate_massloss_step` ·
`transport_lag.py`(대조 기준으로 남기거나 지운다) — **5자리**. 시험은
`test_dynamics.py` 36건 · `test_session58_transport_lag.py` 8건 · `test_gates_after_*`
192건 · `test_session55_gates.py` 170건이 걸린다(전이 표본이 있으므로). 데이터셋에
전이 행이 지금 **0건**이라 재생성은 「전이 행을 처음 얹는 것」이 된다.

**먼저 정할 것(사람)**: ⓐ 5장 등가길이를 배관 길이로 읽어 지연을 낼 것인가 ⓑ
지연 뒤에도 6장 ③(τ ∝ M) 정합성 기준을 그대로 둘 것인가 — 지연은 M 이 아니라
`L/v` 에 비례하므로 τ 하나로 안 잡힌다 ⓒ 「샘」 전이의 상수 M 근사(#38)를 같이
